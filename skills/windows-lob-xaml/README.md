# Windows LOB XAML Skill (draft)

A draft, distilled Copilot skill for designing and building data-dense
line-of-business (LOB) apps in WinUI 3 / Windows App SDK.

Derived from the internal **windows-design-xaml** plugin and narrowed for the
hackathon to the surfaces third-party LOB developers actually ship: data grids
and tables, dashboards and metric cards, forms and data entry, task/status
tracking, filtering/sorting/grouping, navigation shells, and Windows Design
System compliance (theming, High Contrast, accessibility).

See `SKILL.md` for the full guidance. This is a work-in-progress draft.
